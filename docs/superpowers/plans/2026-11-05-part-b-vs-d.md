# Part B vs Part D Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/tools/part-b-vs-d`: for one drug, show which Medicare benefit pays in each setting, why, and the dollars.

**Architecture:** Four new data feeds load CMS and FDA facts into Postgres through the existing `importRelease` pipeline. A pure rule function turns facts and user answers into one result per setting, and a pure dollars function compares lawful pathways. A server page loads the facts, and a client component holds the answers so the contract rate never leaves the browser.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind v4, Drizzle with Postgres (PGlite in tests), Vitest, Playwright, Papa Parse, fflate, `node:zlib`.

**Spec:** `docs/superpowers/specs/2026-11-05-part-b-vs-d-design.md`

## Global Constraints

- Work on branch `claude/part-b-vs-d`. Do not push or merge until the operator says so.
